## Why Simulation?

Simulation allows us to:
1.  **Test safely**: No risk of breaking expensive hardware.
2.  **Train faster**: Run simulations faster than real-time.
3.  **Generate data**: Create infinite training data for AI.

## Tools
*   **Gazebo**: The standard simulator for ROS 2. Good for physics.
*   **Unity**: A game engine used for high-fidelity visualization and human-robot interaction.
